## Спецификации реализации

| Компонент | Логика | Зачем это нужно |
| :--- | :--- | :--- |
| **Смена темы** | JS + `localStorage` | Переключает UI на темную/светлую тему с сохранением выбора пользователя при перезагрузке страницы. |
| **Экспорт в PDF** | CSS `@media print` | Оптимизирует разметку под А4, блокирует разрывы карточек и сбрасывает темные фоны для экономии тонера. |
| **Архитектура UI** | CSS Grid / Flexbox | Двухколоночная адаптивная сетка, автоматически перестраивающаяся в одну колонку на экранах смартфонов. |
| **Оптимизация** | Векторная графика (SVG) | Все контакты и кнопки реализованы на SVG. |
| **Типографика** | Локальные `.woff2` | Шрифты в стиле BI-платформ загружаются локально из папки `/fonts`. |
